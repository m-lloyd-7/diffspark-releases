# DiffSpark releases

Signed, notarized DiffSpark builds for Apple silicon Macs. This repository holds release assets only, no source.

**Install:** download `DiffSpark-<version>-arm64.dmg` from the [latest release](https://github.com/m-lloyd-7/diffspark-releases/releases/latest), open it and drag DiffSpark to Applications. Installed apps then update themselves from this repository.
